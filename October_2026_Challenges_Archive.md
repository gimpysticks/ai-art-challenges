# October 2026 — Challenge Sources and Midjourney Prompt Archive

Archived November 1, 2026.

## Scope

This archive preserves the complete text of the eight Markdown files in October_2026_Challenge_Library.zip and all 62 dated Midjourney prompts produced for October 1–31 in this conversation, plus the October 4 replacement prompt (63 prompt versions total). Prompts are preserved as issued, including mistakes. Instagram captions, slide overlays, and audio suggestions are outside this prompt-only transcript. No images are embedded.

## Corrections and provenance

- October 4, Set 2: the initial Last Autumn Dragon version was replaced at the user’s request with Guardian of the Red Forest. Both versions are retained.
- October 9, Set 2: The Orchard Keeper was deliberately substituted for the source schedule’s Last Autumn Dragon to avoid repetition.
- October 27, Set 2: Pumpkin Mimic was used and credited in error. The correct Myst entry is Burnt Orange + Burgundy + Gold. The user had already published the erroneous version.
- October 28, Set 1: Pumpkin Mimic is the correct source entry, but repeated the already published October 27 subject. No replacement prompt was generated after the user raised this problem.
- October 6, Set 2: the generated scene did not visibly include the House component of Haunted + House + Windows.
- October 21, Set 2: the generated prompt omitted the credited MonAI entry It Had a Pumpkin Head; the historical output is retained unchanged.
- October 31: both prompts explicitly include Halloween as requested.
- The source files below are the authoritative date mappings. Generated scene text and credits should not override them. The Rocket selections are the user’s personal schedule, not host-assigned daily themes; Myst’s list permits flexible participation.
